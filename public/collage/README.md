# Collage asset pack

Generated 2026-10-20 for the clubhouse-wall redesign. 1024x1024, webp + jpg.

- paper-kraft, paper-newsprint, paper-cork — surface textures
- sticker-cars, sticker-hoops, sticker-run, sticker-hardware, sticker-paintball — club badges (sticker on torn scrap)
- cutout-helmet, cutout-sneaker — magazine cut-outs on white

Cut-outs sit on white: use `mix-blend-mode: multiply` (or a `clip-path`/mask) so the white drops out on paper.
Prompted as flatbed scans / phone snapshots, not renders — keep them mildly imperfect in layout (rotation, tape, overlap).
